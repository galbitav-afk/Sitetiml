# 👑 הממלכה של גל

אתר שמקליט שיעורים שלמים (גם 3 שעות רצוף) ומלווה את הסטודנט עד המבחן: תמלול, סיכום לפי נושאים, מבחן אמריקאי, כרטיסיות לחזרה מרווחת, מחברת קורס מאוחדת, סימולציות מבחן, תוכנית לימוד וצ'אט על החומר.
לכל משתמש חשבון פרטי (הרשמה במייל), כך שאפשר לשתף את הקישור עם עוד אדם ולכל אחד יהיו הקורסים שלו.

> **🆕 גרסת Claude (בלי שרתים ובלי תשלום):** https://claude.ai/artifact/3d1RjRBWF92U5EdBC3MrVP. הקוד והפרטים ב-[`artifact/`](artifact/README.md).
> שאר המאגר הוא גרסת האתר העצמאי (Next.js + Supabase), שכוללת גם הקלטה ותמלול מתוך האתר.

## ארכיטקטורה

```
דפדפן ── הקלטה במקטעים של 3 דק׳ ──► IndexedDB (האודיו נשאר במחשב)
   │
   │  מעבד יחיד לכל הדפדפן (Web Locks):
   │    מקטע ─► /api/transcribe ─► OpenAI / Groq
   │    כל 30 דק׳ ─► /api/ai/part ─► Claude
   │    סוף שיעור ─► /api/ai/lesson-meta + quiz + flashcards (במקביל)
   ▼
Supabase: Auth (מייל) + Postgres עם Row Level Security לכל משתמש
```

* **Next.js 15**, TypeScript, Tailwind v4, TanStack Query, Dexie.
* **Supabase** להרשמה ולמסד הנתונים. כל טבלה מוגנת ב-RLS (`user_id = auth.uid()`), כך שמשתמש לא יכול לראות או לשנות נתונים של אחר.
* **Claude** עם פלט מובנה (סכימות Zod) ו-fallback בצד השרת. כל נתיבי ה-API דורשים משתמש מחובר, ואפשר גם להגביל ל-`ALLOWED_EMAILS`.
* **תמלול** דרך כל שירות תואם OpenAI.

## הרצה מקומית

```bash
npm install                 # מעתיק גם את ffmpeg.wasm אל public/ffmpeg
npx supabase start          # Supabase מקומי (דורש Docker)
cp .env.example .env.local  # ממלאים URL ומפתחות
npm run dev
```

המיגרציות נמצאות ב-`supabase/migrations/`. בפרויקט Supabase בענן מריצים אותן ב-SQL Editor (ראו `docs/SETUP.md`).
