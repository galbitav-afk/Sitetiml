# 📓 מחברת שיעורים

אתר שמקליט שיעורים, מתמלל אותם תוך כדי השיעור, ובסופו מסכם אותם ויוצר מבחן אמריקאי. כל קורס נאסף למחברת אחת שמאחדת את כל השיעורים לפי נושאים.

## מה יש באתר

- **הקלטה ישירות מהדפדפן**, במחשב ובטלפון. ההקלטה נשמרת במכשיר כל 10 שניות, כך שגם אם הדף נסגר לא מאבדים את השיעור, ואפשר להמשיך מאותה נקודה.
- **תמלול תוך כדי תנועה.** ההקלטה מחולקת למקטעים של 3 דקות, וכל מקטע נשלח לתמלול מדויק ברגע שהוא מסתיים, כך שבסוף השיעור התמלול כמעט מוכן. במקביל מוצגת **טיוטה חיה** בחינם מזיהוי הדיבור של הדפדפן (Chrome / Edge / Safari).
- **העלאת הקלטה קיימת** (MP3, M4A, WAV, WEBM, וידאו). הקובץ מחולק בדפדפן לקטעים ומתומלל.
- **⭐ סימון רגעים חשובים** והערות אישיות במהלך השיעור. Claude מדגיש אותם בסיכום.
- **סיכום אוטומטי** בסוף כל שיעור: תקציר, נושאים, מושגי מפתח, "הכי חשוב לזכור" ומשימות.
- **מבחן אמריקאי** של 8–12 שאלות עם הסבר לכל תשובה, ושמירת ציונים.
- **מחברת קורס**: Claude מאחד את כל השיעורים לפרקים לפי נושאים, עם מילון מושגים ודף הכנה למבחן. אפשר להדפיס או לשמור כ-PDF, ולהוריד כ-Markdown.
- תמלול מלא עם השמעת ההקלטה המקורית של כל קטע, וחיפוש בתוכו.
- עברית מימין לשמאל, עיצוב רספונסיבי, ומצב כהה אוטומטי.

## איך זה עובד

```
מיקרופון → מקטעי שמע של 3 דק׳ → IndexedDB (במכשיר)
                 │
                 ├─► /api/transcribe → שירות תמלול (OpenAI / Groq)   ← תוך כדי השיעור
                 │
סוף השיעור ──────┴─► /api/summarize  → Claude: סיכום + מבחן (JSON מובנה)
כל הסיכומים ───────► /api/notebook   → Claude: מחברת קורס מאוחדת
```

- הנתונים (הקלטות, תמלולים, סיכומים) נשמרים **בדפדפן שלך** (IndexedDB). השרת משמש רק כמתווך שמחזיק את מפתחות ה-API בסוד.
- התור ממשיך לבד אחרי רענון או ניתוק מהאינטרנט.

## הפעלה מקומית

```bash
npm install
cp .env.example .env.local   # ומלא את המפתחות
npm run dev
```

פתח את http://localhost:3000.

| משתנה | חובה | תיאור |
|---|---|---|
| `ANTHROPIC_API_KEY` | ✔ | מפתח Claude לסיכומים, מבחנים ומחברת |
| `OPENAI_API_KEY` | ✔* | מפתח לתמלול (ברירת מחדל: `gpt-4o-transcribe`) |
| `TRANSCRIBE_BASE_URL` / `TRANSCRIBE_API_KEY` / `TRANSCRIBE_MODEL` | | לשימוש בשירות תואם OpenAI אחר, למשל Groq עם `whisper-large-v3` |
| `APP_PASSWORD` | | מומלץ באתר ציבורי: סיסמה משותפת שמונעת מזרים לבזבז את הקרדיט שלך |

\* או `TRANSCRIBE_API_KEY`.

## העלאה לאוויר (Vercel)

1. ייבא את המאגר ב-Vercel.
2. הגדר את משתני הסביבה שלמעלה. מומלץ להגדיר גם `APP_PASSWORD`.
3. Deploy. מיקרופון בדפדפן דורש HTTPS, ו-Vercel מספק אותו אוטומטית.

## מגבלות ידועות

- **אייפון:** Safari עלול לעצור הקלטה כשהמסך ננעל. האתר מבקש מהמכשיר להשאיר את המסך דלוק (Wake Lock), אבל כדאי להשאיר אותו פתוח בזמן השיעור.
- הנתונים שמורים בדפדפן אחד. מעבר מכשיר או ניקוי נתוני הגלישה מוחקים אותם. סנכרון לענן (למשל Supabase) הוא השלב הבא המתבקש.
- העלאת קובץ ארוך מאוד (מעל כשעתיים) עלולה להיות כבדה לזיכרון בטלפון. במחשב זה עובד טוב יותר.
