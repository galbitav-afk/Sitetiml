# 🚀 העלאת "הממלכה של גל" לאוויר, צעד אחר צעד

בסוף המדריך תהיה לך כתובת קבועה, למשל `https://gal-kingdom.vercel.app`, שאפשר לשלוח לבת הזוג.
כל אחת נרשמת עם המייל שלה, ולכל אחת יש קורסים וסיכומים פרטיים.

⏱️ **זמן משוער:** 30–40 דקות, פעם אחת. **עלות קבועה:** 0 ₪ (Supabase ו-Vercel חינמיים בהיקף הזה). משלמים רק על שימוש ב-AI: בערך 2–3 דולר לשיעור של 3 שעות (ראו סעיף 7).

---

## שלב 1: מסד נתונים והרשמה (Supabase)

1. נכנסים ל-<https://supabase.com>, לוחצים **Start your project** ונרשמים (אפשר עם GitHub).
2. **New project**:
   * **Name:** `gal-kingdom`
   * **Database Password:** סיסמה חזקה. שמרו אותה, אבל האתר לא צריך אותה.
   * **Region:** `Central EU (Frankfurt)`, הקרוב לישראל.
   * לוחצים **Create new project** ומחכים כ-2 דקות.
3. **יצירת הטבלאות:** בתפריט הצד לוחצים **SQL Editor** ואז **New query**.
   * פותחים במאגר את הקובץ `supabase/migrations/20261107000000_init.sql`, מעתיקים את כל התוכן, מדביקים ולוחצים **Run**. אמורה להופיע ההודעה `Success. No rows returned`.
   * חוזרים על אותו הדבר עם הקובץ `supabase/migrations/20261107000100_search.sql`.
4. **המפתחות:** **Project Settings** (גלגל השיניים), אחר כך **API** (או **Data API**). מעתיקים:
   * **Project URL**, שנראה כמו `https://abcdefgh.supabase.co`.
   * **anon public key** (או **Publishable key**), מחרוזת ארוכה.
5. **הגדרת מיילים:** **Authentication**, אחר כך **Sign In / Providers**, אחר כך **Email**. האפשרות צריכה להיות מופעלת (זו ברירת המחדל).
   * **Confirm email:** כשהאפשרות פעילה, כל נרשם מקבל מייל אימות. שירות המיילים החינמי של Supabase מוגבל לכמה מיילים בשעה, וזה מספיק לשני אנשים. כדי לוותר על שלב האימות, כבו את האפשרות.

> את **URL Configuration** משלימים בשלב 4, אחרי שיש כתובת לאתר.

## שלב 2: מפתחות AI

### Claude (סיכומים, מבחנים, כרטיסיות, מחברת, צ'אט)
1. נכנסים ל-<https://console.anthropic.com> ונרשמים.
2. **Billing**: מוסיפים אמצעי תשלום וטוענים קרדיט (10 דולר מספיקים להרבה שיעורים).
3. **API Keys**, אחר כך **Create Key**, ומעתיקים את המפתח (מתחיל ב-`sk-ant-`).

### תמלול (אחת משתי האפשרויות)
**OpenAI (ברירת המחדל, איכות גבוהה בעברית):**
1. <https://platform.openai.com>, אחר כך **Billing** (טוענים קרדיט), אחר כך **API keys**, אחר כך **Create new secret key**.
2. מעתיקים את המפתח (מתחיל ב-`sk-`).

**Groq (זול ומהיר מאוד):**
1. <https://console.groq.com>, אחר כך **API Keys**, אחר כך **Create API Key**.
2. בשלב 3 משתמשים במשתנים של Groq במקום OpenAI.

## שלב 3: העלאה ל-Vercel

1. מוודאים שהקוד נמצא ב-GitHub בענף `main` (ממזגים את ה-Pull Request של הענף).
2. נכנסים ל-<https://vercel.com> ונרשמים עם GitHub.
3. **Add New…**, אחר כך **Project**, ובוחרים את המאגר `sitetiml`, אחר כך **Import**.
4. פותחים את **Environment Variables** ומוסיפים:

| שם | ערך | הערה |
|---|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | ה-Project URL משלב 1 | חובה |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | ה-anon/publishable key משלב 1 | חובה |
| `ANTHROPIC_API_KEY` | `sk-ant-…` | חובה |
| `OPENAI_API_KEY` | `sk-…` | לתמלול עם OpenAI |
| `ALLOWED_EMAILS` | `you@gmail.com,partner@gmail.com` | **מומלץ מאוד**: רק המיילים האלה יכולים להשתמש ב-AI, כדי שזרים לא יבזבזו את הקרדיט |

   **ל-Groq במקום OpenAI**, מוסיפים במקום `OPENAI_API_KEY`:

| שם | ערך |
|---|---|
| `TRANSCRIBE_BASE_URL` | `https://api.groq.com/openai/v1` |
| `TRANSCRIBE_API_KEY` | מפתח ה-Groq |
| `TRANSCRIBE_MODEL` | `whisper-large-v3` |

5. **Deploy**. אחרי 2–3 דקות מקבלים כתובת, למשל `https://sitetiml.vercel.app`. אפשר לשנות אותה ב-**Settings**, אחר כך **Domains**, למשל ל-`gal-kingdom.vercel.app`.
6. **Settings**, אחר כך **Functions**: מוודאים ש-**Fluid Compute** מופעל (בפרויקטים חדשים זו ברירת המחדל). הוא מאפשר לסיכום לרוץ עד 5 דקות.

## שלב 4: חיבור הכתובת ל-Supabase

ב-Supabase: **Authentication**, אחר כך **URL Configuration**:
* **Site URL:** הכתובת מ-Vercel, למשל `https://gal-kingdom.vercel.app`.
* **Redirect URLs**, אחר כך **Add URL**: `https://gal-kingdom.vercel.app/**`

בלי השלב הזה, הקישורים במיילי האימות ואיפוס הסיסמה יובילו לכתובת לא נכונה.

---

## שלב 5: הרשמה ושיתוף 🎉

1. נכנסים לכתובת, לוחצים **הרשמה**, ממלאים שם, מייל וסיסמה.
2. שולחים את הכתובת לבת הזוג. היא נרשמת עם המייל שלה (שצריך להופיע גם ב-`ALLOWED_EMAILS`).
3. **פרטיות:** ההפרדה נאכפת במסד הנתונים עצמו (Row Level Security). אף משתמש לא יכול לראות או לשנות נתונים של משתמש אחר, גם לא דרך גישה ישירה ל-API.

---

## שלב 6: טיפים לשימוש

* **הקלטה מהמחשב:** Chrome או Edge, מחשב מחובר לחשמל, בלי מצב שינה. מותר לגלוש באתר בזמן ההקלטה, רק לא לסגור את הלשונית.
* **שיעור בזום או טימס:** באולפן ההקלטה בוחרים "שמע מהמחשב", ובחלון השיתוף בוחרים את הלשונית של הזום ומסמנים "שיתוף אודיו".
* **הקלטה מוכנה?** בדף הקורס, "העלאת קובץ". עובד עם אודיו ווידאו בכל אורך.
* **העיבוד רץ בדפדפן** של המחשב שבו ההקלטה נשמרה. אם סוגרים את האתר באמצע, העיבוד ממשיך מאותה נקודה בכניסה הבאה.

## למפתחים: הרצה מקומית

```bash
npm install
npx supabase start          # מסד נתונים, הרשמה ומיילים מקומיים (דורש Docker)
cp .env.example .env.local  # ומלאים: את ה-URL והמפתח ש-supabase start מדפיס
npm run dev
```

מיילים בהרצה מקומית נתפסים ב-Mailpit בכתובת <http://127.0.0.1:54324>.
