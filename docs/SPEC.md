# 👑 הממלכה של גל: אפיון מוצר ו-UX/UI

> גרסה 2.0 · מסמך אפיון שעליו מבוסס האתר. מתאר למי האתר מיועד, אילו בעיות הוא פותר, איך הוא בנוי, ואילו החלטות התקבלו בדרך ולמה.

## 1. חזון

**אתר אחד שמלווה את הסטודנט מהרגע שהמרצה פותח את הפה ועד המבחן.**
מקליטים שיעור שלם (גם 3 שעות רצוף), ומקבלים בסופו תמלול מלא, סיכום מסודר לפי נושאים, מבחן אמריקאי, כרטיסיות לחזרה, מחברת קורס מאוחדת, סימולציית מבחן, תוכנית לימוד עד המבחן, וצ'אט שעונה על שאלות מתוך החומר.

**מדדי הצלחה**
1. אפס שיעורים אבודים: הקלטה לא נעלמת בגלל סגירת לשונית, ניתוק אינטרנט או מעבר בין דפים.
2. זמן מסוף השיעור ועד סיכום מוכן: עד כ-5 דקות גם בשיעור של 3 שעות.
3. סטודנט שלמד רק מהמחברת והכרטיסיות מרגיש מוכן למבחן.

## 5. ארכיטקטורה

```
┌──────────────── דפדפן (מחשב ההקלטה) ─────────────────┐
│ RecorderProvider ─► מקטעי 3 דק׳ ─► IndexedDB (אודיו)   │
│        │                                              │
│ Pipeline (לשונית מובילה אחת, Web Locks)                │
│   1. תמלול מקטע  ──► /api/transcribe ─► OpenAI/Groq    │
│   2. כל 30 דק׳    ──► /api/ai/part    ─► Claude         │
│   3. סוף השיעור   ──► /api/ai/lesson-meta + quiz +      │
│                       flashcards (במקביל)  ─► Claude    │
└───────────┬───────────────────────────────────────────┘
            │ supabase-js + RLS (כל משתמש רואה רק את שלו)
┌───────────▼─────────── Supabase ──────────────────────┐
│ Auth (מייל + סיסמה / קישור קסם)                         │
│ Postgres: courses · lessons · transcript_segments      │
│           flashcards · quiz_attempts                   │
└───────────────────────────────────────────────────────┘
```

* **Next.js על Vercel** מגיש את האתר ונתיבי API שמחזיקים את המפתחות בסוד ומוודאים שהפונה הוא משתמש מחובר.
* **Supabase** מספק הרשמה וכניסה במייל, ומסד נתונים עם הרשאות ברמת השורה (RLS): **גל ובת הזוג לא רואות זו את הנתונים של זו**, גם אם יש באג בצד הלקוח.
* **Claude** מסכם, בונה מבחנים, כרטיסיות, מחברת ותוכנית לימוד, ועונה בצ'אט. כל הפלטים מובנים (JSON עם סכימה), כך שהממשק יציב.
* **תמלול:** כל שירות תואם OpenAI. ברירת המחדל היא `gpt-4o-transcribe`, ו-Groq הוא חלופה זולה.

## 7. מסעות משתמש מרכזיים

### 7.1 הרשמה ראשונה (פחות מדקה)
1. נכנסים לקישור ← מסך כניסה עם לשונית "הרשמה".
2. שם, מייל וסיסמה ← "יצירת חשבון".
3. (אם אימות מייל מופעל) מקבלים מייל ולוחצים על הקישור.
4. נוחתים בדשבורד ריק עם הזמנה ברורה: "צור את הקורס הראשון שלך".

### 7.2 הקלטת שיעור (המסע הקריטי)
1. "🎙️ הקלטה חדשה" (זמין מכל מקום).
2. **שלב 1, איזה קורס?** בחירה מרשימה, או "＋ קורס חדש" באותו מסך בלי לעזוב אותו. שם השיעור מוצע אוטומטית ("שיעור 4").
3. **שלב 2, מאיפה הקול?** מיקרופון (עם בחירת התקן) / אודיו מלשונית או זום / שניהם, ומד עוצמה חי: "דבר משהו… ✓ נשמע מצוין".
4. **הקלטה.** טיימר גדול, השהיה, ⭐ סימון רגע חשוב (גם Ctrl+B), פתקים עם חותמת זמן, תמלול שמתמלא כל 3 דקות, וסיכום ביניים כל 30 דקות.
5. אפשר לנווט באתר, והפס הצף מראה ⏺ 1:23:45 עם כפתור חזרה לאולפן.
6. "סיום" ← דף השיעור עם התקדמות: "מתמלל את המקטע האחרון ← מאחד סיכום ← בונה מבחן וכרטיסיות".

### 7.3 הכנה למבחן
1. בדף הקורס מגדירים **תאריך מבחן** ← ספירה לאחור בדשבורד.
2. "תוכנית לימוד" ← Claude בונה תוכנית יומית עד המבחן, לפי הנושאים, החולשות והכרטיסיות. הסימון "בוצע" נשמר.
3. כרטיסיות: חזרה מרווחת (שיטת לייטנר), עם "להיום: 23 כרטיסיות" בדשבורד.
4. **סימולציית מבחן:** בחירת שיעורים, מספר שאלות, רמת קושי ושעון אופציונלי. בסוף מקבלים ציון, פירוק לפי נושאים ו"חזרה על הטעויות".
5. "שאל את הקורס": "מה ההבדל בין X ל-Y?" ← תשובה עם הפניה לשיעור.

## 8. מסכים

### 8.1 דשבורד, "הממלכה"
* כותרת: "בוקר טוב, גל 👑" (ברכה לפי שעה).
* **כרטיסי מצב:** קורסים · שעות שהוקלטו · כרטיסיות להיום · ציון ממוצע.
* **מבחנים קרובים:** שם הקורס, "עוד 12 ימים" ופס התקדמות של התוכנית.
* **בעבודה עכשיו:** שיעורים בתמלול או בסיכום, עם פס התקדמות.
* **הקורסים שלי:** כרטיסים בצבע הקורס, עם מספר שיעורים, כרטיסיות לחזרה ותאריך מבחן.

### 8.2 אולפן ההקלטה
* במחשב, שתי עמודות. **ימין:** טיימר, מד עוצמה, כפתורי שליטה, סימניות ופתקים. **שמאל:** תמלול חי וסיכומי ביניים.
* מצבי שגיאה: אין הרשאת מיקרופון (עם הוראות פתרון), אין קול (באנר אדום מהבהב), שמירה נכשלה, אין אינטרנט ("ממשיך להקליט, אתמלל כשהחיבור יחזור").

### 8.3 דף שיעור
* כותרת עם שם (ניתן לעריכה), תאריך, משך וסטטוס.
* **סיכום:** "בקצרה", ניווט נושאים, ונושאים עם **חותמת זמן** (לחיצה מנגנת מהנקודה, אם האודיו במחשב), הכי חשוב לזכור, מושגים, ומשימות.
* **מבחן:** שאלה אחר שאלה, תוצאה עם פירוק לפי נושאים, ו"נסה רק את הטעויות".
* **כרטיסיות:** תצוגת ריבוע עם היפוך ב-3D.
* **תמלול:** חיפוש, השמעת קטע, הורדה כקובץ טקסט.
* **שאל:** צ'אט שמכיר את כל התמלול של השיעור.

### 8.4 מחברת קורס
* תוכן עניינים, פרקים לפי נושאים (עם "מתוך שיעורים 2, 5"), מילון מושגים מאוחד, ודף הכנה למבחן.
* הדפסה ל-PDF מעוצבת (כל פרק בעמוד חדש) והורדה כ-Markdown.
* התראה "נוספו 2 שיעורים מאז העדכון".

## 11. האם אפשר להריץ את זה "דרך הקישור של Claude"?

**חלקית בלבד, ולכן האתר בנוי כאתר עצמאי.**

דף Artifact של Claude יכול לזהות מי צופה בו, לשמור נתונים לכל משתמש ולשאול את Claude שאלות טקסט. **אבל:**
1. אין לו גישה למיקרופון, ולכן הוא לא יכול להקליט.
2. אין לו שירות תמלול אודיו: Claude מקבל טקסט ותמונות, לא קול.
3. כדי שבת הזוג תשתמש, צריך להזמין אותה לארגון או כאורחת, ואין שליטה בהרשמה.

**הפתרון:** אתר עצמאי על Vercel ו-Supabase (שניהם חינמיים בהיקף הזה) עם כתובת קבועה, למשל `gal-kingdom.vercel.app`. שולחים את הקישור לבת הזוג, היא נרשמת עם המייל שלה, ולכל אחת יש ממלכה פרטית משלה.
